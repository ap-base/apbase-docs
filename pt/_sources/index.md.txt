# APBase

**Geração inteligente de mapas com alto desempenho para agricultura de precisão.**

O APBase transforma dados de campo irregulares (registros de monitores de
produtividade, amostras de solo e grades de sensores) em mapas, sem exigir
que o usuário escolha manualmente o modelo matemático. O principal ponto
de entrada é `apbase.Map`: informe as coordenadas `x`/`y`, os valores e a
resolução de saída. A biblioteca filtra os dados de origem, trata coordenadas
geográficas de longitude/latitude quando necessário, constrói a grade,
compara IDW com krigagem ordinária e utiliza o modelo com o menor erro de
validação para esse conjunto de dados.

::::{tab-set}

:::{tab-item} Python
:sync: python

```python
import apbase

result = apbase.Map(resolution=10.0)(x, y, z)

result.method                  # "idw" ou "kriging", escolhido pelo erro de validação
result.x, result.y, result.z   # pontos do mapa dentro do contorno, em formato compacto
```

## Por que usar o APBase

- **Um fluxo principal para gerar mapas.** `apbase.Map` reúne as etapas
  necessárias para a maioria dos usuários: filtragem, geração do contorno
  e da grade, ajuste de variograma compartilhado, validação cruzada deixando
  um ponto de fora, seleção do modelo e interpolação final.
- **Seleção automática do modelo matemático.** O processamento compara IDW
  com krigagem ordinária e interpola com o método que apresenta o menor RMSE
  nos dados, dispensando a comparação manual.
- **Processamento orientado ao desempenho.** O fluxo automático reutiliza
  o variograma ajustado na seleção do raio, na validação cruzada e na krigagem
  final, evitando cálculos redundantes.
- **Preparado para pontos irregulares e dados com ruído.** O processamento
  remove registros inválidos, valores atípicos globais e valores atípicos
  espaciais locais antes da interpolação.
- **Valores padrão adequados aos dados.** O raio de busca de `IDW`/`Kriging`
  utiliza o alcance do variograma ajustado quando não é informado explicitamente.

Consulte {doc}`quickstart` para um exemplo completo. Consulte o
{doc}`user-guide/index` e a {doc}`methodology/index` para obter controle
avançado ou examinar a matemática por trás da escolha automática.
