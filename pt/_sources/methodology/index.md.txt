# Methodology

APBase's interpolation methods are standard geostatistical techniques behind
its intelligent mapping pipeline for precision agriculture. You do not need
this section to generate maps with `apbase.Map`; use it when you want to
audit the mathematics, tune an advanced workflow, or understand why one model
won over another.

The default map pipeline currently chooses between IDW and ordinary kriging
by validation error. `apbase.create_map` uses the same selection pipeline as a
functional shortcut. Co-kriging is documented here as an advanced method for
workflows with validated secondary variables.
