Cokrigagem¶

CoKriging extends ordinary kriging to use one or more secondary variables correlated with the primary – e.g. a dense NDVI or soil EC surface alongside a sparse yield sample – to improve the estimate wherever that correlation is real and admissible [9, 10, 11, 12]. Run covariate screening first: CoKriging does not test its inputs itself, and an unrelated or inadmissible secondary degrades the estimate rather than improving it.

This is an advanced method, not the default apbase.Map path. The default pipeline chooses between IDW and ordinary kriging; co-kriging should be used only when secondary variables have been screened and then cross-validated against a plain kriging baseline.

Estimator and constraint¶

Given a primary \(Z_0\) and \(K\) secondaries \(Z_1, \dots, Z_K\), the estimate at a target \(x_0\) pools weighted contributions from every variable’s own local neighborhood:

\[ \hat{Z}_0(x_0) = \sum_{u=0}^{K} \sum_{i=1}^{n_u} \lambda_{u,i} \, Z_u(x_{u,i}) \]

where \(n_u\) is variable \(u\)’s own neighbor count (primary neighbors for \(u=0\), secondary-\(u\) neighbors for \(u \geq 1\)). All three methods below use the same single global unbiasedness constraint \(\sum_{u,i} \lambda_{u,i} = 1\) (standardized ordinary cokriging), rather than one constraint per variable – this is what keeps the system solvable while combining weights across variables that are in different units and different local neighborhoods.

Each secondary is rescaled to the primary’s mean/variance before fitting or interpolating:

\[ Z_u'(x) = \bar{Z}_0 + \left(Z_u(x) - \bar{Z}_u\right)\frac{\sigma_0}{\sigma_u} \]

so that a single shared constraint stays meaningful regardless of the secondaries’ native scales; every equation below assumes \(Z_u\) is already this standardized form.

The block system (ICM and LMC)¶

For ICM and LMC, each variable \(u \geq 1\) searches its own local neighborhood independently (radius/max_neighbors bound every variable’s search, not just the primary’s), so secondaries need not share the primary’s sample locations (heterotopic secondaries work directly). Writing \(C_{uv}(h)\) for the fitted cross-covariance between variables \(u\) and \(v\) at separation \(h\), the weights and Lagrange multiplier \(\mu\) solve

\[\begin{split} \begin{bmatrix} \mathbf{C}_{00} & \mathbf{C}_{01} & \cdots & \mathbf{C}_{0K} & \mathbf{1} \\ \mathbf{C}_{10} & \mathbf{C}_{11} & \cdots & \mathbf{C}_{1K} & \mathbf{1} \\ \vdots & & \ddots & & \vdots \\ \mathbf{C}_{K0} & \mathbf{C}_{K1} & \cdots & \mathbf{C}_{KK} & \mathbf{1} \\ \mathbf{1}^\top & \mathbf{1}^\top & \cdots & \mathbf{1}^\top & 0 \end{bmatrix} \begin{bmatrix} \boldsymbol\lambda_0 \\ \boldsymbol\lambda_1 \\ \vdots \\ \boldsymbol\lambda_K \\ \mu \end{bmatrix} = \begin{bmatrix} \mathbf{c}_0 \\ \mathbf{c}_1 \\ \vdots \\ \mathbf{c}_K \\ 1 \end{bmatrix} \end{split}\]

where block \(\mathbf{C}_{uv}\) holds \(C_{uv}(d_{ij})\) between variable \(u\)’s neighbors and variable \(v\)’s neighbors, and \(\mathbf{c}_u\) holds \(C_{0u}(d_{i0})\) from variable \(u\)’s neighbors to the target. This is exactly one \((n_0 + \cdots + n_K + 1)\)-sized linear system per target, generalizing kriging’s single block to \(K+1\).

ICM and LMC differ only in how \(C_{uv}(h)\) is built from the fitted model:

ICM (Intrinsic Coregionalization Model). A single shared shape (model + range), fit jointly over every one of the \(\binom{K+1}{2}\) variable pairs, scaled per pair by two \((K+1)\times(K+1)\) matrices – a nugget matrix \(\mathbf{B}_0\) and a partial-sill matrix \(\mathbf{B}_1\):

\[\begin{split} C_{uv}(h) = \begin{cases} \left(\mathbf{B}_0\right)_{uv} + \left(\mathbf{B}_1\right)_{uv} & h = 0 \\ \left(\mathbf{B}_1\right)_{uv} \left(1 - g(h)\right) & h > 0 \end{cases} \end{split}\]

with \(g\) the shared shape function (spherical/exponential/gaussian, selected the same way as Variograma, chosen by total fit error summed across all pairs). \(\mathbf{B}_0\) and \(\mathbf{B}_1\) are fit independently per pair by closed-form weighted least squares, then each checked for positive semidefiniteness (PSD) via a Cholesky attempt with a small relative floor (CoKrigingNonPSDCoregionalizationError if either fails) – both matrices are checked, not just the sill: the nugget contributes its own additive covariance component at \(h=0\) (structurally identical to LMC’s own nugget structure below), so a nugget matrix that is not itself PSD corrupts the block system with a negative eigenvalue just as readily as a bad sill matrix would, even though independent per-pair fits routinely produce a near-zero nugget diagonal for low-noise data.

LMC (full Linear Model of Coregionalization). \(S\) nested structures (index \(0\) = nugget, \(1, \dots, S{-}1\) continuous, at geometrically spread ranges), each with its own \((K+1)\times(K+1)\) coefficient matrix \(\mathbf{B}^{(l)}\):

\[ C_{uv}(h) = \sum_{l : h=0 \text{ or } l>0} \left(\mathbf{B}^{(l)}\right)_{uv} \left(1 - g_l(h)\right)_{[l>0]} \]

i.e. every structure contributes at \(h=0\), only the continuous structures (\(l \geq 1\)) attenuate with \(g_l\) for \(h>0\). Coefficients are fit by the Goulard & Voltz (1992) algorithm [13]: block-coordinate descent, alternating a closed-form weighted-least-squares update per structure (holding the others fixed) with an eigendecomposition-based projection onto the PSD cone (clip negative eigenvalues to 0, reconstruct) after each update. Unlike ICM, PSD-ness is guaranteed by construction every sweep, not checked post-hoc – LMC trades ICM’s single shared shape for \(S{-}1\) independently-shaped continuous structures, at the cost of a heavier iterative fit.

Collocated cokriging (MM1)¶

Collocated cokriging (Markov Model 1) [14, 15] instead uses only the primary’s own neighborhood plus, for each secondary, a single colocated datum – the secondary’s value at (or nearest to) the target itself, not a full local neighborhood of secondary points. Under the Markov screening assumption (the secondary only informs the primary through their shared spatial location, not through the secondary’s own spatial structure), the cross-covariance collapses to a fixed multiple of the primary’s own covariance:

\[ C_{0u}(h) = \rho_u \, C_{00}(h) \qquad\qquad C_{uv}(0) = \rho_u \rho_v \, C_{00}(0) \; (u, v \geq 1) \]

where \(\rho_u\) is the primary-secondary correlation from CrossVariogram. This reduces the system to primary-neighborhood size plus \(K\) (one row/column per secondary) plus one constraint row – far smaller than ICM/LMC’s full block system, at the cost of needing the secondary value available at every interpolation target (pre-interpolate a sparse secondary onto a denser point set first if needed) and of the simpler screening assumption itself.

Collocated is cheapest and needs the least fitting, but assumes the Markov screening effect holds and requires secondary coverage at every target. ICM captures genuine multi-point secondary structure with one shared shape; LMC relaxes that to a shape per structure when a single shared shape underfits the data, at higher fitting cost.

Local parameters¶

Like Kriging, radius/max_neighbors bound every variable’s local search (with min_neighbors as the floor below which a target returns NaN); unlike plain kriging, ICM/LMC apply these bounds independently per variable, so a sparse secondary and a dense primary each get their own appropriately-sized neighborhood at the same target.
