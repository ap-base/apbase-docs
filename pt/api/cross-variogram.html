apbase.cross_variogram¶

Cross-variogram fitting and secondary-variable screening for cokriging.

Runs before apbase.cokriging: fits a generic cross-variogram model between any two variables, and screens candidate secondary variables against a primary via a Fisher z-test (significance) and a Cauchy-Schwarz check (admissibility).

class apbase.cross_variogram.CrossVariogram(*, n_lags=50, max_pairs=100000, max_distance=0.0, max_colocation_dist=None)¶

Base: object

Fit an empirical cross-variogram model between two variables.

Symmetric in a/b – no fixed primary/secondary role. Used by screen_secondary_variables() and by CoKriging’s ICM/LMC fit for every variable pair.

a and b may be sampled at different coordinates: the native fit pairs them via nearest-neighbor join, accepting a match within max_colocation_dist.

Parâmetros:

  • n_lags (int) – Same meaning as Variogram, applied to the paired sample.

  • max_pairs (int) – Same meaning as Variogram, applied to the paired sample.

  • max_distance (float) – Same meaning as Variogram, applied to the paired sample.

  • max_colocation_dist (float | None) – Maximum distance accepted by the nearest-neighbor join. None requires an exact coincidence.

Exemplos

>>> import numpy as np
>>> from apbase.cross_variogram import CrossVariogram
>>> xa = np.ascontiguousarray([0.0, 10.0, 0.0, 10.0, 5.0])
>>> ya = np.ascontiguousarray([0.0, 0.0, 10.0, 10.0, 5.0])
>>> za = np.ascontiguousarray([5.0, 7.0, 8.0, 10.0, 6.5])
>>> zb = np.ascontiguousarray([1.2, 1.6, 1.7, 2.1, 1.4])
>>> cross = CrossVariogram(n_lags=4).fit(xa, ya, za, xa, ya, zb)
>>> cross.rho > 0.0
True

apbase.cross_variogram.screen_secondary_variables(x0, y0, z0, candidates, *, alpha=0.05, correction='bonferroni', min_abs_rho=0.3, max_violation_fraction=0.1, max_colocation_dist=None, n_lags=50, max_pairs=100000, max_distance=0.0)¶

Test each candidate secondary variable for admissible use in cokriging.

Runs, per candidate: a Fisher z-test on the primary<->candidate correlation (Fisher1921) and a Cauchy-Schwarz admissibility check on the fitted cross-variogram (Journel1978, Myers1982). A candidate is kept only if both the correlation is significant (and practically relevant, via min_abs_rho) and the cross-variogram is admissible.

Parâmetros:

  • x0 (ArrayLike) – Primary variable source coordinates and values.

  • y0 (ArrayLike) – Primary variable source coordinates and values.

  • z0 (ArrayLike) – Primary variable source coordinates and values.

  • candidates (dict[str, tuple[ArrayLike, ArrayLike, ArrayLike]]) – Mapping of candidate name to (x, y, z) source arrays.

  • alpha (float) – Significance level for the Fisher z-test, per candidate before correction.

  • correction (Literal['bonferroni', 'none']) – "bonferroni" (default when len(candidates) > 1) divides alpha by the candidate count to control the family-wise false-positive rate; "none" tests each candidate at alpha directly.

  • min_abs_rho (float) – Practical-significance threshold: a candidate is rejected even with a significant p-value if |rho| < min_abs_rho.

  • max_violation_fraction (float) – Maximum fraction of evaluated lags allowed to violate the Cauchy-Schwarz bound before a candidate is rejected as inadmissible.

  • max_colocation_dist (float | None) – Passed through to CrossVariogram for the primary<->candidate pairing. None requires an exact coincidence.

  • n_lags (int) – Passed through to both the primary/candidate Variogram fits and the CrossVariogram fit.

  • max_pairs (int) – Passed through to both the primary/candidate Variogram fits and the CrossVariogram fit.

  • max_distance (float) – Passed through to both the primary/candidate Variogram fits and the CrossVariogram fit.

Retorna:

selected: subset of candidates that passed both tests, ready for CoKriging(...).fit(x0, y0, z0, secondaries=result.selected). report: per-candidate diagnostics (rho, p-value, admissible fraction, decision, status) for every candidate, kept or not.

Tipo de retorno:

ScreeningResult

Notas

A candidate rejected for “amostra insuficiente” (fewer than 4 colocated pairs) or an invalid fitted model is recorded in report with decision=False and the reason in status – it does not raise.

Exemplos

>>> result = screen_secondary_variables(x0, y0, z0, {"ndvi": (xn, yn, zn)})
>>> result.selected
{'ndvi': (xn, yn, zn)}
