# APBase

APBase é uma biblioteca Python para geração de mapas e análise de dados espaciais voltada à agricultura de precisão. Integra filtragem de dados, análise de variogramas, interpolação por IDW e krigagem e validação cruzada, com foco em desempenho e seleção automática do método de interpolação conforme os dados.

**[Acesse a documentação do APBase](https://ap-base.github.io/apbase-docs/)** para consultar as instruções de instalação, os exemplos de uso e a referência da API.
