# APbase

APbase é um pacote Python pronto para produção para geração de mapas e análise
de dados espaciais em agricultura de precisão. Ele integra filtragem de dados,
análise de variogramas, interpolação por IDW e krigagem e validação cruzada,
com foco em desempenho, seleção automática do método de interpolação e uso
direto em APIs, workers, containers, serviços em nuvem, MCPs e Agentes de IA.

**[Acesse a documentação do APbase](https://ap-base.github.io/apbase-docs/)** para consultar as instruções de instalação, os exemplos de uso e a referência da API.
